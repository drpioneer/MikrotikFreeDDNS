# MikrotikFreeDDNS - скрипт обновления Dynamic DNS записи для freedns.afraid.org

Скрипт автоматически обновляет DDNS IPv4 адрес для freedns.afraid.org.
Скрипт не имеет зависимостей от сторонних функций и скриптов.
Настройка скрипта сводится к указанию домена и хэша.
Скрипт необходимо закинуть в 'System/Scripts' после чего настроить его запуск по расписанию в 'System/Scheduler'.
Типовое значение периодичности запуска скрипта = одна минута.
Смена IP-адреса отражается соответствующей записью в журнале устройства.
