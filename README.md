# MikrotikFreeDDNS - скрипт обновления Dynamic DNS записи для freedns.afraid.org

Скрипт автоматически обновляет DDNS IPv4 адрес для freedns.afraid.org.
Скрипт не имеет зависимостей от сторонних функций и скриптов.
Настройка скрипта подразумевает правку значений локальных переменных в начале тела скрипта.
Тело скрипта необходимо закинуть в 'System/Scripts' после чего настроить запуск скрипта по расписанию в 'System/Scheduler' с необходимым периодом времени (типовое значение = одна минута).
